─── 실행 방법 ────────────────────────────────────────────────────────

[빠른 시작 — UI/미션 컨텍스트만 확인]
  ./scripts/run_backend.sh   → http://localhost:8080
  · 브릿지 없이도 미션 시작·노드 필터·요약 카드·ETA 동작
  · 봇 마커만 부재(브릿지 안 떴기 때문)

[정식 모드 — 실 봇/ROS2 환경]
  1회 의존성:  pip install --user 'websockets>=12' PyYAML
  ROS2 source: source /opt/ros/humble/setup.bash
               export ROS_DOMAIN_ID=27
  3개 터미널:  ./scripts/build_frontend.sh     # dist 생성
               ./scripts/run_backend.sh         # :8080
               ./scripts/run_bridge.sh          # :9090
  접속:        http://localhost:8080
               or 같은 LAN의 호스트 PC에서 http://<VM_IP>:8080
               (백엔드 시작 로그의 "lan=..." 줄)

[로봇 안 뜰 때 체크]
  ① 브릿지 :9090 LISTEN  ② websockets 16+ 설치
  ③ TB3·PC 같은 SSID/서브넷  ④ ROS_DOMAIN_ID=27 일치
  ⑤ ROS_LOCALHOST_ONLY=0  ⑥ AP 격리 OFF

[폰 앱(PWA) 설치]
  사전 조건: 폰과 GCS PC가 같은 Wi-Fi(같은 서브넷, AP 격리 OFF),
            방화벽 8080 허용(sudo ufw allow 8080/tcp)
  1. 폰 브라우저로 http://<GCS_PC_IP>:8080 접속
  2. Android Chrome — 우상단 ⋮ → "홈 화면에 추가" / "앱 설치"
     iOS Safari    — 하단 공유 → "홈 화면에 추가"
  3. 홈 화면 아이콘 탭 → standalone 풀스크린 실행


─── GUI 사용법 ──────────────────────────────────────────────────────

[화면]
  PC: 좌(미션/위치추정/로봇) · 중앙(맵) · 우(요약/매니퓰레이터)
      · 하단(로그 스트립)
  폰: < 1024px에서 단일 컬럼 스택, 맵 60vh 고정

[주요 조작]
  1. 로그인: 상단 우측 "관리자 로그인" → 미션 명령 활성화
  2. 미션 시작: 목적지 드롭다운 선택 or 맵 노드 탭 → "주행 시작"
              → 경로 노드만 표시 + 다음 도착=빨강·도달=초록
     · 브릿지 미가동 시: "브릿지 미연결 — 의도는 추적되나 봇은
       정지 상태" 메시지. 노드 필터는 정상 동작.
  3. 위치 추정: 토글 ON → 맵에서 클릭+드래그(방향) → 떼면 발행
              (5cm 미만 무시, 다른 클라에 4초간 미러)
  4. 일시정지/재개/초기화/긴급 정지: 미션 제어 카드의 각 버튼
  5. 맵: 휠·핀치 줌, 드래그 패닝, 노드 탭으로 목적지 지정
  6. 로봇 상태: 좌측 색점+한글명+좌표, 우측 배터리·상태·역할·연결
  7. 분석 탭: 상단 헤더 "분석" → ETA 예측·이력·속도·미션 시간 차트
  8. 다중 클라: PC·폰 동시 접속 시 명령·위치추정·로그 자동 동기화
